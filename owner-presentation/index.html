3パターンから考える

 A｜既存サイトを一部改善B｜集客用LPを1本つくるC｜ターゲット別LP
向いている場合既存サイトをできるだけ活かしたい動画との相性をシンプルに見たい3本の対象が明確に異なる
メリット既存情報を活用できる／改修範囲が小さい既存サイトを大きく触らず済む／受け皿が明確／将来拡張しやすい動画ごとに最適化できる
留意点動画ごとの訴求を分けにくい3本の対象が大きく違う場合は情報量が増える制作・更新範囲が増える
今のところ Bが一番合いそう

ブログから「NEWS / UPDATES」へ

更新のためのブログではなく、
情報を届ける仕組みへ

BEFORE｜従来型ブログ

  • 更新が続きにくい
  • 古い記事が残る
  • 投稿操作が負担になる可能性

AFTER案｜NEWS / UPDATES

掲載するもの：

  • 営業・休館／クラス変更
  • イベント・大会結果
  • 新クラス・キャンペーン
  • 重要なお知らせ
ブログを書くことが目的じゃなくて、必要な情報だけ更新できればOK。
スタッフが無理なく続けられる方法を優先します。やり方は運用を見ながら決めます。
